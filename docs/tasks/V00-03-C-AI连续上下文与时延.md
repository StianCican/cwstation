# V00-03-C AI连续上下文与通联时延 v1

2026-10-21用户同意AI自主语义判断并要求考虑通联速度。状态：限定验收完成，当前任务关闭，暂无新实施任务。固定脚本建议撤回；AI负责语义，确定性程序负责有效性/授权/执行。本切片交付同一receive/reply上的连续上下文与回复/等待/结束判断，不声称多轮真实发送已完成。

## 六项边界

1. 可见缺口：现有AI只看一轮文本，回复后不再处理，速度只有固定idle而无整轮时延。完成条件：同一receive可显式开启连续AI模式，第二轮请求含第一轮真实接收及明确未发送的提案历史，AI自主reply/wait/end，CLI实际显示连续turn及速度指标。信息不足等待，不硬编码QSO对话。
2. 复用：apps/rig-receive.ts→packages/assistant/src/reply.ts同一个createReplySession/ReplySessionImpl→唯一chat.requestChatCompletion。以可选模式扩展原实现，旧单轮默认/严格JSON/取消/03-B模拟发送保持兼容；禁止另建conversation provider/第二HTTP/独立假收报链。
3. 最小修改：reply.ts、rig-receive.ts、cwrig.ts usage、原receive-reply专项、README/本项证据。连续模式必须生产CLI实际调用。新增--reply-continuous、--reply-wpm（5..60，默认20，仅连续模式）、--reply-budget-ms（100..10000，默认5000，仅连续模式）；既有idle仍1000..10000默认2500。若参数细节需局部调整须证据记录，不开放设备速度写入。连续模式与03-B发送flag互斥：现有未决intent阻断与单次会话尚不支持连续发送；明确拒绝组合，不换目录/删记录/用模拟结束时间解除真实unknown。
4. 无新入口/服务/依赖/存储格式/记录真源。连续上下文只在原回复会话内存，限定单对端、至多12轮/12000字符上下文（或更紧的现有合理限制），到限明确停止而不无声删历史。连续模式可用独立严格JSON {action:reply|wait|end,text,reason}，reply仍30字节/大写/字符/^校验，wait/end正文为空；旧单轮原schema不变。模型可自主wait/end，wait不自动重试，同一数据不轮询模型；end后不再请求。历史必须标注received与proposed_not_sent/invalidated/failed，不能把提案当实际发送。当前用户资料只有显式own/peer，缺RST/姓名等不得编造。
5. 非替换，不迁移/删旧路径。原类可在连续模式reset下一轮，但不能再造同职责长期控制器。新非空白输入撤销旧提案，在途中止并合并未收完文本，等下一idle再请求；晚到响应不发布，最多一个有效请求，新文本不可触发无限并发。明确区分finish正常EOF与cancel采集失败，连续end/limit/取消后定时器/监听器回收。保护.local-backups/20261021-152132-qso-context/含dirty补丁、全部源码/未跟踪、dist（GNU tar比较exit0）、非凭据profile和protected哈希；写入前源码归档内容/模式复核。DSH修改权为上述实现/测试/README/evidence，Codex维护MEMORY/ROADMAP/本任务。
6. 速度与验收：已有真实DeepSeek1.856秒仅单样本，不保证SLA。保留idle2500ms则理想该样本总等待约4.4秒，模型预算从boundary计时、总等待须分别报告；连续请求超预算取消且迟到不得发布，不能沿用30秒才失败的实机等待。事件显示idle等待/模型耗时/从最后非空白到发布总时延，使用单调时钟。发报时长复用现有packages/signal的encodeCwText/buildTimeline，按声明WPM估算，不能自造摩尔斯表或从文本chunk间隔猜实际码速；不支持估算的合法字符返回明确不可估，不能让速度显示改变合法性。不把估算当物理完成或设置电台速度。

测试只补连续2轮上下文未发事实、AI wait/end、慢请求预算/迟到抑制、新输入撤销合并、历史限额、取消/EOF、WPM和时延/CLI参数互斥，复用现有fetch/decoder注入；跑受影响原receive-reply/cw-trial专项一次（失败或修改再定向复验）、build一次。最终编译CLI+既有解码能力/本地脚本化HTTP证明第二轮实际携带上下文；测试使用确定性HTTP不冒充真实AI质量，不再调用真实模型/凭据/设备/全仓/全平台。预计一个实现切片，DSH约10分钟先交可审结果，遇到原类不能合理扩展/重大公共接口或新增结构需要时带证据升级，不强行扩建。
