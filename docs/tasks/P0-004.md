## 实现要求

1. TS 独立 `cwwave` CLI：`prepare --text <text> --out <task.json> [--wpm 20] [--tone 600] [--sample-rate 8000] [--snr 10] [--seed 42]`，`verify --task <task.json> --result <result.json>`，纯 JSON 和明确退出码。严格校验所有参数/未知旗标。prepare 不运行发射，不自动启动 Julia，任务文件 exclusive 写入、不能覆盖已有数据。
2. 文本编码复用小型现有库，不另造 Morse 编码器：可评估 npm `morse@0.1.0`（README MIT），固定版本并检查实际源和许可证。按字符调用编码，严格拒绝库不支持的字符，不能静默丢弃。首版支持 A-Z、0-9、空格和已验证的基本标点（至少 / ? . ,）；折叠空格、转大写，保留原始文本与规范文本。若该库实际行为不符合标准，提交证据后换合适现有库。不要复制库代码或 fork。
3. Task contractVersion=1、algorithmVersion、text/normalizedText、Morse words（每个字母为 .- 字符串，按词分组）、wpm、toneHz、sampleRateHz、snrDb（可为 null 表示干净场景）、seed、rampMs。双方独立运行时校验：非有限值、布尔冒充数值、未知版本、空报文/空词、非法 Morse、超长输入、过量样本拒绝。固定范围：wpm 5..60、sampleRate 8000..48000 整数、tone 200..2000 且小于 Nyquist、snr -20..60 或 null、seed 0..2^31-1 整数、文本 <=400 字符、总时长 <=120s。防止恶意任务无限分配。
4. Julia `julia/CWSignal.jl` 模块与 `julia/run_task.jl` 入口；支持 `CWSignal.run_task(taskPath, outputDir)` 以便 Syslab include 后调用，也支持 launcher 脚本命令行 ARGS。点1、划3、元素间1、字符间3、词间7单位；点长 1.2/wpm 秒，整数样本单位量化说明误差，无多余末尾间隔。载波乘短余弦沿以免硬开关；用实际样本边界生成 ground truth key-down segments，不以有噪音后的零点检测反推。
5. awgn 使用整个报文（包括间隔）的 measured power，加固定种子噪声；记录 SNR 定义与实际估计。clean/noisy 同比例归一化至峰值<=0.95 后写 WAV，避免截幅破坏 SNR。至少生成 clean.wav、noisy.wav（无噪音可相同）、result.json；单声道，采样率/长度一致。输出目录必须新建且不存在，拒绝覆盖，失败清理仅本次新建临时输出；先写临时同级目录再原子发布，不删用户已有目录。
6. Result 有 task 原始字节 SHA256、算法版本、任务版本、有效参数、环境 Julia/相关包版本、seed、时长/样本数、时间量化误差、实测信噪比、keyDownSegments、artifact 相对路径/字节数/SHA256。保留全部 unknown/执行控制无交互。prepare/verify 输入与结果文件上限合理。TS verify 用结构校验与 SHA256 检查 task、WAV 内容及格式（可用现有解析库或限定格式），拒绝 path traversal/绝对路径/目录外 symlink、未来版本、错配任务/音频。不能只验证 JSON 存在。
7. examples/signal/ 提供简短可复现任务示例，README 说明 WSL/Windows 路径、Syslab include/run 用法、不依赖 Julia 全球 PATH、seed 复现范围是已记录环境。不要把共享 Julia 环境可用等同于已验证所有工具箱。
