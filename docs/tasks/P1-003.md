## 目标与最小方案

读取 AGENTS.md、MEMORY.md、ADR0004、P1-002证据。复用现有Node本地管道，不换TCP、不建权限平台。Codex建议：PowerShell/Win32小型适配，在任何pipe listen之前为当前Node进程token设置默认DACL（当前实际Windows用户SID与SYSTEM允许，NETWORK SID拒绝），Node/libuv创建pipe后查实际DACL。先实测libuv是否采用该默认DACL；不成立时报告证据与最小备选，不自行扩大架构。

目标：普通其他用户不得读写/发送命令；阻止网络登录访问，即使同用户凭据。SYSTEM/管理员提权能绕过OS隔离不是本项目对抗边界。不创建账户，不索要凭据。

## 要求

1. SID来自实际Windows token，不能信任USERNAME/环境变量作授权依据。PowerShell脚本参数为当前PID/验证pipe，不允许任意SID覆盖。使用结构化参数与spawn，无shell拼接；路径带空格可用。脚本输出JSON不含密钥。
2. 权限准备在listen前，实际pipe验ACL完成之前拒绝所有RPC（包括stop/propose/approve/transmit），不触发启动恢复/ready。初始化失败关闭listener、释放锁，无静默降级。每个新pipe实例须继承限制，不只第一个连接测ACL。
3. DACL精确允许当前SID与SYSTEM；拒绝NETWORK SID；无Everyone/Anonymous/Users/AuthenticatedUsers泛化allow；保护DACL免继承。核查owner、null DACL、ACE类型/权限/SID等，不以字符串包含SID作为通过。记录实际进程token变更影响范围与是否需要恢复，禁止改变全局系统设置。
4. 避免pipe创建/抢占：验证同名已有服务的拒绝行为，客户端若需验证pipe server身份报告最小处理；不能拿文件锁当其他用户管道命名空间隔离。doctor只在实际验证后报告权限已验证，说明管理员/SYSTEM边界及其他用户/远程测试实际覆盖。
5. 工具可缺失/权限拒绝/超时/坏JSON/ACL不符都fail closed。helper有界，不残留PS/daemon。Linux不启动PS。
