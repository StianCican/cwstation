## 目标与范围

实现独立 `packages/assistant/src/` 与 `apps/cwai.ts`。仅输入经过校验的
StationState JSON 快照，生成解释/建议，不连接 daemon，不读取数据库，
不调用 approve/transmit/resolve/shell/串口。用户显式选择文件即同意将此最小
状态发送给所配置后端；不得上传其它文件、日志或环境变量。

提供 `cwai validate-config --config <file>`、
`cwai explain --config <file> --state <file>`，JSON输出与确定性错误码。
配置version1：provider为disabled/mock/chat-completions，endpoint为完整请求URL，
model、apiKeyEnv、timeoutMs、maxOutputTokens；精确校验，拒绝未知字段。
真实后端使用标准fetch POST的chat-completions文本子集，不指定服务商，
不承诺所有兼容服务都支持。HTTPS允许；HTTP仅localhost/127.0.0.1/[::1]，
拒绝URL用户密码/query/fragment、重定向及非法scheme。配置不含凭据值，
apiKeyEnv只指定环境变量名，联网时才读取，validate不要求凭据。

mock本地确定性输出，disabled不联网并明确AI不可用。输出仅包含建议文本、
provider/model和advisoryOnly=true，不生成执行命令。设置输出token上限、
请求超时与响应字节上限；超时覆盖读取body，无重试、无自动切换服务商。
输入状态只接受精确字段、合法有限数值/布尔/模式/阻止原因，并限制文件大小。
不泄露后端错误body、Authorization、环境凭据或原始fetch异常消息。
不保存密钥；操作界面与系统凭据存储在后续任务实施。
