# AI-001 v1：只读状态建议验收

日期：2026-10-06。范围：开发版模块、CLI、离线及本机模拟 HTTP。
真实模型、系统凭据存储、成品界面与发布包不在本次验收范围。

## 实现

- `packages/assistant/src/`：version1 配置、状态白名单、建议输出、disabled/mock/
  chat-completions 文本后端。与控制核心独立，没有设备、批准或执行工具。
- `apps/cwai.ts`：`validate-config` 与 `explain`，JSON 输出及确定性退出码。
- `examples/assistant/`：配置和状态样例、字段说明；package.json 新增运行命令。
- 网络请求只包含所选状态与模型参数；凭据在联网前从指定环境变量读取，
  不落盘。拒绝重定向、URL凭据、query/fragment及非回环HTTP；无自动重试。
- 请求超时包含响应读取；响应上限64KiB，建议上限4000字符。错误不回显
  后端body或原始网络异常，成功文本含当前凭据原文也拒绝输出。

## 限制

目前输入是显式文件快照，不是实时daemon连接，建议不能作为设备停止或
发射许可证明。未选择/验证真实模型供应商；兼容文本接口不等于所有API可用。
token上限不能保证费用上限。环境变量凭据仅为开发入口，界面保存凭据
须后续接系统凭据存储。阻止原因是白名单中的文本字段，使用者应先检查
文件内容，不能据此声称快照自动脱敏。Windows管道隔离P1-003仍未完成。
