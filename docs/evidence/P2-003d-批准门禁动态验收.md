## 专项覆盖

| 场景 | 实际断言 |
|---|---|
| 首次同频接入 | 历史批准revokedAt、提案cancelled、generation+1落盘 |
| 调频/实际USB或未知模式/连接代次/同频实例/filter/availability变化 | 每次新指纹撤销一次，重复不刷代次，核心mode仍CW、deviceMode真实保留、零执行 |
| 持续相同指纹 | 后台轮询超过2秒，采样时间更新、fresh=true，无额外代次，门禁仍拒绝既有批准 |
| 9类非法报告 | 无owner、send能力、非法/不安全代次、过期/未来/不一致时间、非只读来源、非法filter拒绝，失联撤销一次、恢复再次撤销，旧批准不恢复 |
| 批准与执行 | CW+simulation仍不能新批准；已有批准再次approve被拒；transmit未消费、未写execution |
| 请求合并/关闭晚到 | refresh共享promise/只发一次watch，close后晚到不更新、不重新连接 |
| IPC超时与新实例 | 超时失联撤销，恢复新IPC上下文再次撤销，无reconnect命令 |
| 持久化失败 | 显式注入saveState失败，真实SQLite事务回滚；gate清缓存，频率/代次回滚，恢复不清核心fault latch；不是实际磁盘损坏试验 |
| unknown保留 | Fake故障产生unknown，重建控制器恢复后设备报告/实例变化仍保留unknown与禁发 |
| 核心guard | 已有批准再次检查、消费前再检查、拒绝零消费/零执行；终态重复查询不再次检查或模拟键控 |
| RPC三方法迟到 | propose/approve/transmit各在timeout/disconnect/daemon.stop期间等待hook，解除等待后不生成提案/批准/执行，不键控；timeout先收到request_timeout |
| 真实daemon子进程显式绑定 | 从--rig-endpoint获取报告，doctor fakeOnly=false/approvable=false、dev.state即使环境开关为1仍禁用、批准/发送拒绝、退出0；独立报告服务仍可访问 |
