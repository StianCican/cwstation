# P2-015 受控 CW 发送闭环

日期：2026-10-14  
范围：离线仲裁验证、受控 CW 试验实现与模拟闭环。**没有打开 COM17、没有连接真实电台、没有发送射频。**

## 实现

- `packages/devices/src/civ-read-arbiter.ts` 的八查询仲裁保留为独立注入式候选；新增 `tests/civ-read-arbiter.test.ts` 覆盖启动顺序、外部容量、取消、超时迟到帧、TTL/墙钟回退和断线隔离。
- `packages/devices/src/serial.ts` 新增独立 `openCwTrialSerialTransport`。它要求 `confirmKeyingOff:true`，固定 19200/8N1 生命周期，白名单只含八项固定读取、`17 45`（E）、`17 54 45 53 54`（TEST）和 `17 FF`（停止）；原 `openSerialCivTransport` 仍只读。
- `packages/cw-trial/src/session.ts` 使用单 transport、单 parser、单在途查询槽，读取完整八项上下文，重读后才允许一次 E/TEST；停止只能发当前会话的 `17 FF`。FB/FA、写失败、超时、RX 或功率设置均不被解释为完成/停止证据。
- `packages/cw-trial/src/record.ts` 在发送前追加并 `fsync` intent；任何 intent、损坏或超限记录都保持 unresolved，重启不会自动清除或再次发送。
- `apps/rig-controld.ts --cw-trial` 是显式试验路由；普通 `rig.sh` 与只读服务不变。`scripts/cw-trial.sh` 在 WSL 下调用 D 盘 Windows 原生 Node（可用 `CWSTATION_WINDOWS_NODE` 覆盖），必须另加 `--confirm-keying-off` 才能进入真实 TTY 流程。

## 真实 COM17 短报文试验

用户在 IC-7300 保持零功率的条件下运行：

```text
bash scripts/cw-trial.sh --port COM17 --confirm-keying-off --message E
```

读回上下文为 `14250000 Hz / CW / FIL2`，TX 频率一致，TX 状态 `RX`，Split/RIT/XIT 均 `OFF`，Break-in 为 `SEMI`；八项预检全部通过。用户输入 `E` 后，Command 17 收到 `FB`，记录为 `ack_observed`；用户输入 `S` 后，`17 FF` 也收到 `FB`，记录为 `ack_observed`；随后输入 `Q` 退出。

这次现场结果证明 COM17、19200 CI-V 链路、上下文读取、一次短报文写入和停止命令应答链路可运行。`FB` 不证明 CW 已完成，亦不证明 `17 FF` 已使电台停止键控；功率 0、Break-in、等待时间和退出同样不能替代该证据。软件没有把本次试验标记为“发射完成”或“停止已确认”。

用户随后确认听到 IC-7300 侧音。现场结论因此增加：本机 CW 键控路径确实出现可听反应。侧音属于电台本地音频，不是天线端或外部接收机测得的射频证据，不能单独证明实际辐射、报文完成或停止时刻。
