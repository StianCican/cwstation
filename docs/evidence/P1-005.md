# P1-005 只读真实串口验收

日期：2026-10-10。状态：独立cwrig只读接入已验收；不是daemon或发射验收。

## 实现与协作

- serialport精确固定13.0.0，原生绑定动态加载；包内Linux/Windows预编译绑定均成功加载。
- DSH两次全局headless执行均因`STREAM_CLOSED: SSE stream ended without [DONE]`退出1，留下serial.ts初稿，无DSH测试通过证据。Codex接手修改权并完成CLI、测试、审查修正和验收。
- 复用CivReadOnlyClient和现有解析，civ.ts未改。串口只允许固定94/E0地址03/04六字节帧；白名单冻结、写入复制、回复等write/drain完成才投递，缓冲上限4096字节。
- open/set/flush/write/drain/close有超时；延迟open成功仍由原会话负责关闭，关闭未知不释放同进程登记。初始化错误中止；正常close事件独立结算，错误事件有监听。CLI finally额外检查transport关闭结果，避免client吞关闭错误后输出成功。
- Ctrl-C使用AbortSignal，包含打开阶段。CLI清理超时后报错并退出，由OS回收进程句柄；库不会把无法确认关闭标为isClosed=true。没有自动重试、枚举或扫地址/波特率。
