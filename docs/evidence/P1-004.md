## 实现与边界

新增（仅任务授权范围）：

- `packages/devices/src/civ.ts`：只读 CI-V 协议、流式 parser、只读会话。
  - 窄接口：`CivReadOnlyClient` 只有 `readFrequency()` 与 `readMode()`；没有
    raw/send/write/PTT 入口。请求字节由模块内私有 `buildReadRequest` 生成，
    `index.ts` 不导出任何通用命令构造器（测试断言包外无 `buildReadRequest`/
    `encodeFrame`）。
  - 注入式 `CivTransport`（`write`/`onData`/`onClose`/`close`），`onData`/
    `onClose` 返回取消订阅函数用于会话关闭时精确清理。
  - 默认地址电台 `0x94`、控制端 `0xE0`；显式地址校验拒绝广播 `0x00`、
    电台范围外的 `0xe0..`、控制端范围外的值以及两端相同。
  - `CivFrameParser` 有界流式解析：连续 `FE FE` 才起帧，跨 chunk 组帧，
    一 chunk 多帧，帧内再遇 `FE` 重启，超过 `maxFrameBytes`（固定上限，
    默认 32）丢弃并重同步；`bufferedBytes` 可观测缓存不随大 chunk 增长。
  - 只接受 `to == controller && from == radio` 且命令为当前期望命令的帧；
    回显、其他地址、`00/01` transceive 一律忽略。期望回复畸形、`FA`(NG)、
    意外 `FB`(OK) 使查询失败。
  - 解码拒绝：频率必须 5 字节、逐字节 BCD 合法、值在 `0..9999999999 Hz`；
    模式必须 2 字节（模式码 + 过滤器 01/02/03），未知模式码与非法过滤器报错。
  - 同一时刻只允许一个查询，并发查询抛 `CivBusyError` 且不锁死会话。
  - CI-V 无事务 ID：超时、写失败（同步抛出或 rejected Promise）、transport
    断连、无效期望回复都会关闭并**锁死**会话，之后所有查询抛
    `CivSessionError`；不自动重试、不自动重连。`close()` 中止在途查询、
    清理 timer 与 listener，幂等。
  - 注释明确：注入 transport 是可信测试入口而非权限隔离；读取结果是非原子
    快照，不代表 `txBusy`、授权或可发射。
- `packages/devices/src/simulator.ts`：纯内存模拟 transport。收到合法读请求后
  按 `chunkSize`（默认逐字节）先回显请求、再回连续回复；固定 14 025 000 Hz、
  模式 CW、FIL1。所有回显与回复作为一个连续字节流发出，避免拆包序列交错。
- `packages/devices/src/index.ts`：公共出口，仅窄接口与模拟 transport。
- `apps/cwrig.ts`：只接受 `cwrig simulate`。其他命令/参数（含空参数、
  `read`、`simulate extra`、`--config` 等）返回退出码 2 与 usage JSON。
  成功输出单行 JSON：`source:"simulation"`、`readOnly:true`、`frequencyHz`、
  `mode`、`filter`。不读取配置、数据库或 daemon。
- `tests/civ.test.ts`：最终29项离线测试；DSH交付版本27项（见下）。
- `examples/rig/README.md`：Linux/Windows 构建与模拟命令、只读边界、真实设备
  未接入的限制。
- `package.json`：新增 `cwrig`/`cwrig:dev` 脚本；未改其他字段。

未改动核心接口、daemon、配置、数据库、授权逻辑或其他模块。

## 覆盖对照

| 任务要求 | 测试 |

| 包外无任意命令构造器 | `package public surface exposes no ...` |

| 地址/回显/transceive 隔离 | echo/other addresses/transceive、unsolicited frames |
| 错误长度/BCD/模式/filter | frequency decoding、malformed mode/frequency 参数表 |

| 并发 busy | concurrent read rejects busy |
| 超时后迟到回复不能复用 | timeout locks ... late reply is not reused |
| write 失败（同步/异步） | synchronous and asynchronous write failures |
| 断连（有/无在途） | transport disconnect、disconnect with no pending |
| close 清理 timer/listener | close aborts ... unsubscribes listeners（含超时后仍为 closed） |
| 模拟 transport 与 CLI 无设备路径 | simulated transport、cwrig simulate、cwrig rejects |

## 局限与交接

- 未接入任何真实串口实现；模拟通过不代表已连接电台、已授权或可发射。
- 频率 `0..9999999999 Hz` 只是五字节BCD容量校验，不证明设备支持该频率或可发射；读取结果
  是非原子快照，与 `txBusy`/授权无关。
- 显式地址校验只覆盖广播与保留/控制端范围，未声称覆盖所有 ICOM 机型语义。
- 本任务未产生真实设备证据，也未验证 USB 控制线电平；开真实端口前仍需确认
  USB SEND/CW/RTTY 映射 OFF 与控制线分配（见 `docs/evidence/IC-7300-connection-notes.md`）。
- 会话锁死是“本次会话不可复用”，没有自动重连；跨进程/跨设备恢复不在本任务范围。
- DSH已退出交接，Codex接手修改权。最终独立结果见下节。

## Codex独立审查

修正任务初稿频率上限：手册规格接收范围含74.8MHz，69.999999MHz不是
协议容量上限。五字节BCD按容量校验，后续设备范围独立判断。
补运行时非字节BCD拒绝、结束符纳入帧长度上限、连续多FE前导重同步，
关闭后的异步write失败不得改变closed状态。新增两个回归用例及74.8MHz边界。
DSH自测初版模拟器曾将回显与回复逐字节交错，已修为连续字节流再交接。
