# ADR 0005：AI 分发与权限边界

- 状态：接受（用户同意首版方向；具体适配器尚未实现）
- 日期：2026-10-06

## 背景

Windows 成品主要分发给同学和学弟；Linux 主要由作者使用，也会对外公布。
接收者不应依赖作者的开发环境、模型账户或凭据。

## 决定

基础台站不依赖 AI 或网络。AI 为应用内可配置能力，首版优先支持使用者
自备云端 API 凭据并承担调用费，预留本地模型接口。不建设作者统一托管服务，
不在发布包中携带作者密钥，不默认捆绑本地模型或要求特定 GPU。

云端和本地后端通过适配接口提供建议或结构化提案。核心保持唯一操作入口，
负责校验、批准、互锁、急停和恢复；AI 不取得任意 shell、设备、批准或
解除故障工具。首批场景优先评估状态解释、待确认 CW 内容和通联建议，
具体范围和验收另立任务；实时键控不依赖模型响应。

优先使用系统凭据存储，配置和诊断导出排除秘密。使用者选择允许发送的
上下文，不默认上传完整日志或原始音频。不因故障自动切换服务商。
断网、超时或无效输出显示 AI 不可用，人工操作仍可使用，控制命令不自动重发。

## 后果与未决项

使用者需要准备云端账户和凭据；首次配置需检查连接并说明费用归属。
本地接口预留不等于本地模型已交付，具体后端能力必须分别验收。

服务商、模型、适配契约、预算上限、凭据存储实现和支持系统仍待选型。
在干净 Windows 环境验证配置、凭据保护和故障降级后才可声称成品可用。
同用户下有任意 shell 权限的外部 Agent 不受仅靠提示词的工具限制保护。

本决定不批准 Windows 管道桥接实现，也不授权 USB 接入或真实发射。
