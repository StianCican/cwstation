# ADR 0008：IC-7300 发射准备先采用离线规划，真实后端单独验收

- 状态：接受（仅限本 ADR 的干运行范围）
- 日期：2026-10-11

## 决定

1. 当前 IC-7300 继续由只读 `rig-statusd` 独占 COM17；不增加第二个串口持有进程。
2. 首个发射准备切片只实现 CI-V CW 报文规划：校验 ASCII、长度、地址，生成可审计的十六进制帧。
3. 规划模块没有 transport 参数，不打开串口、不调用 `write`，并将结果标记为 `dryRun: true`、`executable: false`。
4. CLI 只提供 `cwrig tx --dry-run --text <ASCII>` 和 `cwrig tx --dry-run --stop`，没有真实 `tx` 命令。
5. 真实后端必须先解决唯一设备持有者。倾向将状态读取与受控写入合并到一个设备服务，由只读客户端和发射控制共享 IPC；在此决定完成前不得修改只读串口白名单。
6. Julia/MWORKS 继续只负责波形、时序测试向量和离线分析，不直接访问电台，也不参与授权、急停或停止确认。

## IC-7300 报文范围

- CI-V 地址：电台 `0x94`，控制端 `0xE0`。
- CW 消息命令：`0x17`，最多 30 个可打印单字节 ASCII 字符。
- 停止载荷：命令 `0x17` 后跟一个字节 `0xFF`；它不是字符串 `"FF"`。
- 帧形状：`FE FE <radio> <controller> 17 <payload...> FD`。

以上只用于离线规划。命令确认、设备回执、队列完成和物理停发仍需真实设备任务分别验证。

## 不在本决定内

- 不向 COM17 发送 `0x17` 或 `0xFF`。
- 不实现 PTT、USB SEND、DTR/RTS 键控或自动重试。
- 不把零功率设置当成软件已证明停止发射。
- 不把 Fake 后端、Julia WAV 或 CAT `OK` 回执当成射频验收证据。
