# ADR-020 最小设备主链路

2026-10-20。用户要求“立刻整顿链路，找到最合理也是最值得优化那个”，此前明确最小闭环、逐步添加。决定先优化既有 `CwTrialSession` 及一次试验CLI，不将新Fake专用服务继续扩建成生产设备平台。

主链：`rig.sh --cw-trial → rig-controld --cw-trial → runCwTrial → CwTrialSession → 注入的模拟或既有受限串口transport`。一个Node进程、一份试验记录，不需daemon/SQLite、公共IPC或常驻平台。现有八查询、真实编解码、人工确认、确认后重读、intent fsync、一次报文及unknown保留直接复用。

这是一次显式受控试验链路，不称为完整日常操作系统。真实intent仍阻断该记录目录后续发送；不通过换目录、自动解除、删除记录追求连续演示。默认rig.sh保持只读，既有真实试验须人工TTY及显式确认，本轮不执行真实设备操作。

旧scripts/cw-trial.sh仅转发到主入口，去掉重复平台选择。`--mode cw-trial --simulate`原IPC实验保留语义与回归，暂停功能扩展；旧daemon/RemoteFake、独立读取候选保留，当前不再投入功能建设，也不贸然删除数据或接口。ADR-019原先将旧试验迁入新Fake服务的后续方向由本决定替代；其Fake实现证据与真实禁用边界仍有效。

先修正主链已确认缺口：取消在确认/重读/intent等待后必须生效；关闭及记录失败不能报成功；发送/停止无应答不能报命令流程成功。保留ACK不等于完成/停止的语义。没有新增协议、记录schema、依赖或框架；不实现自动重连、通用账本或旧历史导入。

设计审议：DSH headless首次读取在55秒限制内未产出最终报告，exit124；用已获得的上下文请求仅输出最终设计意见，exit0。最终意见认可该最小路径，要求先修复上述退出语义及取消顺序并补模拟测试。日志在 `.local-backups/20261020-minimal-chain/dsh-{review,final-review}.log`。这仅是设计交叉审议，实施验收另记。

保护基线fd01497（修改前main干净），忽略dist/logs归档为 `.local-backups/20261020-minimal-chain/outputs-before.tar`，归档完成后tar比较exit0；Harness非凭据cordis配置另存副本。源码与文档可按Git定位回退，不覆盖用户记录。验证与最终审议见P2-017B证据。
