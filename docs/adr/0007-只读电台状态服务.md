# ADR-0007：独立只读电台状态服务

状态：已同意，核心及 Windows 管道实施中（2026-10-11）；客户端迁移和 COM17 服务验收待后续里程碑。

## 决定

新增独立 `rig-statusd` 进程，唯一持有 IC-7300 的串口连接。`cwrig read`、
`cwrig monitor` 及后续界面通过本地 Unix socket 或 Windows 命名管道读取缓存状态。

## 边界

- 服务只允许频率和模式查询，不提供写频率、PTT、SEND、CW、发射或数据库操作。
- 状态包含连接阶段、频率、模式、滤波器、采样时间、过期状态和错误信息。
- 串口断连或查询失败停止轮询；重连必须由用户显式请求。
- 服务与现有控制 daemon 分进程、分端点、分锁，不改变 TxController、SQLite 或控制 RPC。

## 原因

让串口所有权、缓存状态、过期判断和故障处理集中在一个进程，避免 CLI 与监视台各自争抢 COM17。只读服务可以被多个客户端复用，也便于未来接入 UI、日志和 Julia 信号分析。

## 取舍

增加一个服务生命周期和 IPC 协议；Windows 命名管道权限仍需单独验证。第一版只做本地客户端，不做网络监听和自动发现。
