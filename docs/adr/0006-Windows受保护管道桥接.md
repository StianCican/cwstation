# ADR 0006：Windows 受保护管道桥接

- 日期：2026-10-06
- 状态：接受，已实现并完成开发机双平台离线验收；发布环境未验收

Node当前管道默认权限不跟随token默认DACL，创建后收紧不能撤销先前的句柄权限。
Windows采用小型原生桥接进程，CreateNamedPipeW创建时应用限定ACL并拒绝远程。
桥接通过继承的匿名stdio与共享核心通信，不持有批准、恢复或设备业务。
Linux保留Unix socket；公共RPC协议、数据库schema与用户配置不变。

客户端桥接持有同一已核验的管道HANDLE，检查服务token用户和实际ACL后才
发送操作，避免先探测另一个handle再连接的竞态。服务端读回权限才ready。
bridge故障触发现有撤销与有界关闭；父进程退出不留下可用控制服务。
源代码和显式构建纳入工程，运行时不编译。增加进程和构建成本，需两端回归。

同用户/SYSTEM与管理员提权为信任边界，不证明真人批准，不防同用户任意shell。
任务P1-003-v2记录具体限制与故障验收，权限通过前不推进真机控制。
